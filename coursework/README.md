## How to interpret earlier work

These files show how the project developed. They do not replace the current methods, source manifests, or reproducible outputs. The [connection to the current analysis](../docs/coursework_and_current_analysis.md) explains changes in cases, measure construction, hypotheses, and collection status.

The early notes' good/neutral/bad country labels are provisional planning judgments, not measured outcomes. Paper 2 and the presentation use different hypothesis numbering; always identify the document when referring to H1, H2, or H3. A source appearing in the inventory is not proof that its data was collected or used. Links extracted from the supplied files are [indexed here](../metadata/coursework_source_links.csv) and remain unverified unless separately documented.

File renaming does not edit internal titles, correct citations, revise claims, or certify visual layout. The copied files are byte-identical to the supplied originals. Publication or grading status was not established from the files.
