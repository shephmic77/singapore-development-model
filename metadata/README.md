# Definitions and provenance

- [Output catalog](output_catalog.csv): files, row counts, and purposes.
- [Column dictionary](output_column_dictionary.csv): technical names mapped to readable headings.
- Indicator catalogs: definitions, units, directions, and limitations.
- Country crosswalks: explicit matches, aliases, and exclusions.
- Source manifests: URLs, versions, local file times, and checksums.

A checksum identifies a downloaded file; it does not certify statistical quality or grant redistribution rights. File modification times are distinguished from provider publication dates. See [source notes](../SOURCE_NOTES.md).

[Coursework source links](coursework_source_links.csv) preserve links extracted from the supplied documents. These are unverified references or research leads, not evidence that data was collected. The [document manifest](../coursework/document_manifest.csv) records filenames and hashes.
